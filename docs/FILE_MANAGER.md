# 图形化文件管理器（SFTP / FTP / SCP）

NTerminal 的 SFTP / FTP / SCP 连接不再进入命令行式终端，而是在主窗口内以标签页打开双栏图形化文件管理器，不弹出独立窗口。

## 打开方式

- 菜单：**传输 → SFTP / FTP / SCP 文件管理器...**，在连接对话框填写主机和认证信息
- 侧栏：双击已保存的 SFTP / FTP / SCP 会话
- 快速连接：协议选择 SFTP / FTP / SCP，输入 `user@host:port`
- 「新建会话」中选择 SFTP / FTP / SCP 也会打开文件管理器标签页

从「传输」菜单进入时，协议已由菜单项确定，后续连接对话框不再显示「连接类型」下拉框。

## 界面

```
┌ 工具栏：上传 →  ← 下载  新建文件夹  删除  重命名 ─────────────┐
├ 本地  ← → ↑ 路径 [根] [⌂] [刷新] ┬ 远程  ← → ↑ 路径 [根] [⌂] [刷新] ┤
│ 名称 大小 类型 修改时间         │ 名称 大小 修改时间 权限 所有者    │
│ 双击目录进入                    │ 双击目录进入                      │
├────────────────────────────────┴─────────────────────────────────┤
│ 进度条 + 状态                                                   │
└──────────────────────────────────────────────────────────────────┘
```

- 左侧本地文件使用 `QFileSystemModel`，右侧远端目录使用表格
- 两侧都支持前进、后退、上级目录、根目录、主目录与刷新
- 本地根目录为当前盘符根目录（如 `D:/`），远端根目录为 `/`；主目录分别对应用户目录和登录后的家目录，连接后默认显示家目录
- 支持文件和文件夹的双向拖拽：本地 → 远端上传，远端 → 本地下载；
  拖到文件夹行会传入该文件夹，拖到空白处则使用当前目录
- 支持多选上传/下载；目录传输会递归创建目录并传输其中文件
- 新建文件夹、重命名、删除（目录递归删除）
- 大文件传输时进度条内显示百分比，状态栏显示当前文件、已传/总量和实时速度
- 进度更新约 10 次/秒，避免大文件产生过多跨线程事件；关闭标签页时正在传输会先确认
- 同名覆盖前会统一确认；连接失败等信息直接显示在页面状态栏，不再弹窗

## 协议实现

| 协议 | 浏览 | 传输 | 说明 |
|---|---|---|---|
| SFTP | libssh SFTP | SFTP | 显示大小、修改时间、权限、所有者/组 |
| FTP | 被动模式（PASV，IPv6 用 EPSV） | RETR/STOR | 解析 Unix/DOS 风格 LIST；支持 MKD/RMD/DELE/RNFR/RNTO |
| SCP | 复用 SFTP | `ssh_scp_*` | 目录浏览依赖 SFTP 子系统；SCP 当前只传输文件 |

远端操作全部在 GUI 的工作线程中执行（`RemoteFileWorker`），界面不会被网络 I/O 阻塞。列出目录、传输、删除等通过信号回到 GUI 线程更新界面。

## 安全与限制

- 认证信息来自连接对话框或已保存会话；不会写入日志或文件管理器状态
- 与现有 SSH 实现一致，当前版本未做 known_hosts 主机密钥校验；生产环境建议在后续版本补齐
- SCP 模式暂不支持目录传输（会提示），目录传输请使用 SFTP
- 不跟随符号链接目录，避免递归环
- 不支持断点续传、权限修改（chmod）和传输队列并行执行
- FTP 的 LIST 日期/权限解析依赖服务器返回格式；不可解析时仍会显示文件名
- SCP 依赖 libssh 的 SCP API（该 API 在新版 libssh 中标记为 deprecated，但仍是可用实现）

## 故障排查

- **连接失败**：检查主机、端口、用户名/密码或 SSH 私钥；SCP/SFTP 默认 22，FTP 默认 21
- **SCP 无法浏览目录**：服务器未开启 SFTP 子系统；SCP 浏览需要 SFTP
- **上传后目录中看不到**：点击远端刷新；操作完成后界面会自动刷新当前目录
- **目录删除失败**：检查其中是否有无权限删除的文件；删除是递归的
- **FTP 被动模式失败**：服务器/防火墙可能限制被动端口范围；当前实现仅使用 PASV/EPSV
