# NTerminal GUI 重设计方案 —— Xshell 风格现代化

> 状态：**设计评审稿（未实施）**。效果图与可交互原型见本节末。
> 目标：在**不改变任何功能行为**的前提下，将 GUI 从"默认 Qt 控件拼接"提升到
> 商用终端工具（Xshell / SecureCRT / Tabby）的专业观感。

## 3. 设计目标（Xshell 风格要素 → 本项目映射）

1. **统一深色外壳**：菜单/工具栏/侧栏/标签/终端同一色阶体系，冷灰而非纯黑
2. **图标驱动**：16px 线性图标（Lucide 风），1.7px 描边，统一网格
3. **高信息密度**：紧凑行高（工具栏 44 / 菜单 28 / 状态栏 24 / 标签 34），
   侧栏项含 协议图标 + 名称 + 主机副文本 + 状态点 + 协议徽标
4. **状态可视化**：绿=已连接 / 灰=断开 / 黄=串口占用；标签、侧栏、状态栏三处呼应
5. **快速连接**：工具栏内嵌 `协议▾ + user@host:port + 连接`，免开对话框
6. **经典控件而非网红风**：4-8px 圆角、1px 分隔线、无大阴影、无大色块

## 4. 设计规格（Design Tokens）

### 4.1 色板（深色统一，可映射为现有 AppTheme 结构）

| Token | 值 | 用途 |
|---|---|---|
| `bg` | `#17181B` | 窗口底色 |
| `panel` | `#1E2024` | 菜单/工具栏/侧栏/状态栏 |
| `panel2` | `#26282D` | 输入框、悬浮态 |
| `panel3` | `#2C2F35` | 按钮 hover、浮动控件 |
| `border` | `#2E3138` | 1px 分隔线 |
| `borderStrong` | `#3A3E46` | 输入框/按钮描边 |
| `text` | `#D7DBE0` | 主文字 |
| `textDim` | `#8B919A` | 次文字/未激活 |
| `textFaint` | `#5C626B` | 占位符/弱提示 |
| `accent` | `#4C8DFF` | 主操作、选中指示、焦点环 |
| `success` | `#3FB950` | 已连接 |
| `warning` | `#D29922` | 串口/告警 |
| `danger` | `#F85149` | 错误/断开 |
| `termBg` | `#0D1117` | 终端画布（GitHub Dark 系，与 16 套终端主题共存） |

> 关键原则：**应用主题与终端主题解耦但默认配套**。`AppTheme` 提供外壳色板；
> 终端主题继续使用现有 16 套（默认建议从 `solarized-light` 改为 `vscode-dark` 或 `github-dark`）。

### 4.2 字号与间距

- 界面字体：`Segoe UI Variable Text / Microsoft YaHei UI`，基准 12.5px
- 等宽字体：内置 **JetBrains Mono**（qrc 已有），终端 13px / 行高 1.55
- 圆角：输入框/按钮 6px、标签 0、徽标 3px
- 间距栅格：4 / 6 / 8 / 10 / 14 / 16
- 控件高度：菜单 28、工具栏 44、输入框 30、主按钮 30、状态栏 24

### 4.3 主窗口布局规格

```
┌──────────────────────────────────────────────────────────────┐
│ 菜单栏 28：文件 编辑 视图 会话 工具 MCP 帮助        NTerminal 2.0 │
├──────────────────────────────────────────────────────────────┤
│ 工具栏 44：[+新建会话] [SSH▾|user@host:port|连接] │ ⛔ ↻ ⧉ │ 传输 MCP 工具 │… 主题 设置 │
├───────────────┬──────────────────────────────────────────────┤
│ 侧栏 248       │ 标签栏 34：[● web-01 SSH ×][○ db-master ×][+]  │
│ 搜索框         ├──────────────────────────────────────────────┤
│ ▾ 生产环境 (6) │ 终端画布 termBg                               │
│  ● web-01 SSH  │   等宽 13px / 行高 1.55                        │
│  ○ legacy TEL  │                               [↓ 回到底部]    │
│ ► 串口设备 (2) ├──────────────────────────────────────────────┤
│  ● CONSOLE     │ 命令输入 38：> [____________] [➤]              │
│ [+ 新建连接]   ├──────────────────────────────────────────────┤
│               │ 状态栏 24：● 已连接 │ SSH admin@host:22 │ UTF-8 │ 120×32 │ 12ms │
└───────────────┴──────────────────────────────────────────────┘
```

- 会话管理器默认隐藏；「视图 → 会话侧栏」或 Ctrl+B 显示，双击“会话管理器”标题收起；
  重新显示时恢复本次运行中上次的侧栏宽度
- 「视图」菜单提供单终端、左右双栏、上下双栏和 2×2 四终端布局；分屏以标签页为单位，
  新增分屏复用当前连接参数建立独立会话，点击任一分屏即切换当前终端
- 左栏 `1 : 4` 比例改为 `248px 固定 + 可拖拽`（去魔法数）
- 命令输入区保留现有功能（Enter 发送、历史导航），改为单行 `QLineEdit` + 发送按钮
  （现有 QTextEdit 多行输入行为在实施前需确认，若要保留多行则改为可拉伸 2 行高度）

### 4.5 新建连接对话框规格（520 宽）

- 协议选择：**7 段 Segmented 控件**（替代现在的下拉/单选），选中段 accent 底
- 分区：连接（名称/主机/端口）→ 认证（用户名/密码/私钥+浏览）→ 终端（编码/终端类型）
- 每区标题 10.5px 700 大写 + 右侧渐隐分隔线
- 底部：`[✓ 保存会话] … [取消] [连接]`，主操作右置
- 必填校验：主机/端口失焦即时校验，错误红框 + 行内提示（不弹窗）

## 5. 实施路线（建议分 4 期，风险递增）

### P0 设计基石（低风险，1-2 天）—— 见效最快

1. **AppTheme 扩展**：`theme/thememanager.h` 的 AppTheme 增加 tokens
   （bg/panel/panel2/border/text/dim/accent/success/danger/hover/selected/radius）；
   默认主题改为 `default-dark`
2. **QSS 集中化**：新建 `resources/styles/app.qss`（模板占位符 `@accent@` 等，
   由 ThemeManager 加载时替换为当前主题色），qrc 打包；
   删除 `mainwindow.cpp` 中 3 处 `#0078D7` 硬编码
3. **图标体系**：新建 `resources/icons/*.svg`（约 24 个，Lucide 风格 16px）：
   new-session / disconnect / reconnect / duplicate / transfer / server / tools /
   theme / settings / search / folder / folder-open / terminal /
   serial / telnet / chevron / close / send / key / eye / scroll-bottom / split / print
4. **统一字体**：界面字体族与内置 JetBrains Mono 接入 FontManager

### P1 主窗口重构（中风险，2-3 天）

5. 工具栏重建：图标按钮 + 快速连接控件（协议下拉 + 地址框 + 连接）
6. 侧栏：`QListWidget` → `QTreeWidget`（保留两级：分组/会话），
   自定义 delegate 绘制"状态点+协议图标+双行文本+徽标"
7. 标签页：`QTabBar` 自绘（`QProxyStyle` 或 paintEvent）加状态点与底部激活条
8. 状态栏：连接状态/协议/编码/尺寸/延迟（数据来自 TerminalProxy + SessionManager 信号）
9. 命令输入区改单行（或多行可折叠）

### P2 对话框与配套（中风险，1-2 天）

10. ConnectionDialog 按 4.5 节重排（协议 Segmented + 分区 + 行内校验）
11. 主题设置对话框：主题卡片预览（终端 16 色 + 应用外壳实时预览）
12. 菜单：补图标、快捷键标注、分组分隔线

### P3 终端渲染精修（低风险，1 天）

13. 默认字体切 JetBrains Mono 13px；行高 1.55
14. 光标：实心 → 半透明 + 闪烁（已有逻辑则仅调色）；选中区 35% 透明度
15. 终端内边距 10×14px；宽字符/组合字符对齐回归测试

## 6. 不改功能清单（实施时必须保持）

- 三种进程模式（GUI / `--session` / `--test`）与 IPC 流程
- 会话持久化 JSON 格式与旧格式兼容
- TerminalProxy 的全部 VT 解析行为与 16 套终端主题
- 命令输入的 Enter 发送与历史导航语义
- 所有菜单/工具对话框入口（位置可调，功能不可缺）

## 7. 验收标准

1. 应用启动即为统一深色外观，无浅色残留（含菜单弹层、滚动条、对话框）
2. 任意 4 个终端主题切换时，外壳色板不受影响；应用主题切换时全部控件即时更新
3. 侧栏 20+ 会话时滚动流畅（delegate 绘制，无逐项 QSS）
4. 1280×800 下信息密度与效果图一致；HDPI（150%/200%）下无模糊/错位
5. 全部 78 个单元测试通过；新增 UI 层不引入编译警告
